# SampleTweakPack

Starter repo for a [CBT](https://github.com/Jaksuhn/ffxiv-bundleoftweaks/) tweak pack.

This is for using the plugin infrastructure of CBT for tweaks without needing to fork the entire thing to make your own. Tweak packs can be added in the CBT settings and can be auto loaded/updated and function just like existing tweaks.

Create a new repo from this template, add whatever tweaks you want, push, and the workflow will make a dll. Add the repo to CBT and it'll do the rest.
